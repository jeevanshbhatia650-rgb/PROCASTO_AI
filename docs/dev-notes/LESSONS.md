# Lessons

Bugs hit while building PROCASTO-AI: root cause, then fix.

- **AC energy question ranked the wrong manual section.** With two rankers and a 7-section corpus, RRF produced a three-way tie and index order decided (§2.1 beat §4.2). Fix: the dense side embeds heading + opening sentences (what a section is about) and RRF ties break on the BM25 score.
- **"OK go back to the washer" resumed before hearing "washer".** A device-less RESUME clause was allowed to stabilise mid-sentence, so with two parked plans it would bring back the wrong one. Fix: device-less clauses (RESUME included, CANCEL excluded) only stabilise at the end of the utterance.
- **Demo-flow test expected the fault's `state` event to invalidate.** The simulator emits `error_code` first on purpose (so `state=ERROR` handlers already see the code), so the refetch happens on the code event. The test was wrong, not the code.
- **Replay test flaked at 200x speed on Windows.** `asyncio.sleep` below ~15 ms rounds up to the Windows timer tick, so scripted utterances overlapped. Tests run the script at 20x; the real script is 1x.
- **pytest collected a helper called `test_settings`.** Anything starting with `test_` is a test. Renamed to `make_settings`.
- **A sed edit wrote a literal newline into export_schema.py** (replacement text `\n` became a real line break) and it was committed. Fix: edit files with the editor, not sed, when the replacement contains escapes; re-run the module after any scripted edit.
- **Two new regression tests passed with their fixes reverted.** The race test cancelled an LLM job before it ever started (so the buggy cleanup never ran), and the chunked-upload test only checked the 413 status, which the old code also returned after buffering everything. Fix: let the job start before cancelling; test that `read_capped` stops reading early. Rule: revert the fix once and watch the test fail before trusting it.
- **Review findings (code + security reviewers):** a failing real-device command could kill the WebSocket session (now a `CommandError` plus a catch-all in the socket loop); body limits were checked after buffering (now streamed with a cap); signing-key lookups could be triggered by unsigned requests without limit (now a negative cache, a 6-per-minute budget and a bounded cache); Alexa answered anyone when no skill id was set (now fails closed); evicted parked plans, evidence, idempotency keys and severities grew forever (now bounded or retired).
- **Recorded frames found bugs the tests missed.** A bare correction has no clauses of its own (the question lives in the planner), so the UI said "Nothing yet". A spoken resume never counted as a lookup started by speech. Rule: look at the demo at its key moments, not just the test results.
- **uv failed to hardlink from its cache into a new venv (os error 396, cloud-file hardlinks).** Use `UV_LINK_MODE=copy`, which the Dockerfile also sets.
- **Scroll reveals hid the landing page from anything that doesn't scroll.** Sections started at opacity 0 until an IntersectionObserver fired, so full-page captures (and crawlers) saw a blank page. Content is now visible by default; only blocks that start below the fold get hidden, by JavaScript, until they're scrolled to. The hero uses a CSS-only entrance.
- **A label hidden with `display:none` also hides the control's name.** The hood switch lost its accessible name on phones; the e2e run at 390 px caught it. Give icon-only states an `aria-label`.
- **Git Bash rewrites arguments that start with `/` into Windows paths** (`/` became `C:/Program Files/Git/`). Set `MSYS_NO_PATHCONV=1` when passing URL paths to scripts.
- **A module-level cache leaks between tests.** `loadConfig()` caches its promise on purpose, so a later test saw the first test's config. Mock the loader per test instead of stubbing `fetch`.
- **The escapes trap, third time.** A `\x00` in a test written through a bash heredoc landed as a real NUL byte. Rule: write and edit files with the editor tool, never a shell heredoc, when the text has backslashes.
- **`iat` is not sign-in time.** Supabase re-issues access tokens on every refresh, so `iat` is never older than an hour. "Signed in recently" has to come from the `amr` timestamps (ignoring `token_refresh`).
- **An SVG chart pushed the phone layout 11 px sideways.** Implicit grid columns are `auto`, so the chart's 320-wide viewBox became the column's minimum width. Use `grid-cols-1` (`minmax(0,1fr)`); the smoke test now fails on any sideways scroll.
- **Power sampled only when a device reported froze the chart on a quiet home** and made "x s ago" wrong. Sample on a clock.
- **`role="menu"` promises arrow-key navigation.** Without it, a button with `aria-expanded` (a disclosure) is the honest pattern.
- **Search found the right section, the answer still said "not in the manual".** The composer matched the code against the section id, so 4C (listed under 4E) failed after retrieval had succeeded. Found only by asking in the live UI. Rule: when a concept widens (one code, many spellings), grep every place that compares it.
- **Gemini said "relax, all fine" next to fix steps** because it was never told which code was asked about or that the display showed none. Give the model the question's key facts, not just the device state.
- **OneDrive folders look like symlinks to Node** (reparse points), so Remotion's bundler failed with EPERM on `public/shots`. Flattened the files into `public/`.
- **Starlette hands `StaticFiles` an OS path.** On Windows `api/nope` arrives with a backslash separator, so a prefix check on `/` never matched and API 404s turned into the app page. Normalise separators first. (Writing this lesson through a script turned its `\n` into a real newline: the escapes trap again. Edit with the editor.)
